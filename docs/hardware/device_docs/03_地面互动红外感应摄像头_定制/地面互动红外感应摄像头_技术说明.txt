地面互动投影 - 互动摄像头（定制件）技术说明
================================================

【重要说明】
本设备为定制件，硬件资源表中品牌/型号均标注为"定制"，无公开商业型号，
因此无法对应到厂商公开发布的正式电子说明书或 datasheet。
以下信息依据《桂林之眼科技馆 一楼内场 硬件资源表》原始字段整理，
并补充通用技术原理供开发/对接参考。

【资源表原始记录】
- 展项：地面互动投影
- 产品名称：互动摄像头
- 品牌：定制
- 型号：定制
- 数量：4 台
- 规格原文：红外感应摄像头 + 电源适配器（可选 POE 供电）
- 配套软件：摄像头调试软件（定制，4 套）
  规格原文：接入 TUIO 信号；多点处理；互动游戏配置；

【用户现场说明（原话）】
"地面互动：由摄像头红外感应互动，现场多台摄像头拼接，
 软件实现点击功能，软件程序建议点击类触发即可"

【技术原理参考】
1. 红外感应 + 多点触控：这类地面互动通常采用红外多点触摸检测
   （红外摄像头/红外光幕捕获手指或物体遮挡），由摄像头采集红外图像，
   经视觉算法识别触点坐标。
2. 多点拼接：多台摄像头分别覆盖不同投影区域，需做坐标标定与拼接，
   把各摄像头的局部坐标映射到统一的地面/画面坐标系。
3. TUIO 协议输出：触点以 TUIO（基于 Open Sound Control / UDP 3333 端口）
   消息输出给互动程序；TUIO 1.1 / 2.0 规范见同目录上级
   "04_配套软件与协议_TUIO" 文件夹。
4. 点击触发：因红外检测对于"按下-拖动"的连续判定易抖动，
   现场建议仅采用点击类（click / tap）触发，避免拖动等复杂手势。
5. 供电：红外摄像头可选 POE 供电，便于多点位布线。
